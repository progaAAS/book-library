# BookLibrary

Этот проект создан с использованием [Angular CLI](https://github.com/angular/angular-cli) version 17.3.12.

## Скачать зависимости

Перед запуском установите все необходимые зависимости: `npm install`

## Запустить локальный JSON-сервер

Для запуска локального сервера с базой данных в формате JSON выполните команду: `json-server --watch db.json --port 3000`

## Запуск Angular-приложения

Запуск Angular-приложение: `ng serve`
